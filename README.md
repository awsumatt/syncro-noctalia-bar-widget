# SyncroMSP Noctalia Plugins

A collection of Noctalia v5 plugins for SyncroMSP:

- **Syncro Ticket Queue** (`awsumatt/syncro-queue`) - Status bar widget and panel showing open tickets assigned to a technician.

<img width="568" height="464" alt="image" src="https://github.com/user-attachments/assets/e6858471-6031-454f-96fd-6619e38f92a6" />

- **Syncro Ticket Provider** (`awsumatt/syncro-provider`) - Launcher search provider for searching open SyncroMSP tickets.

<img width="648" height="568" alt="image" src="https://github.com/user-attachments/assets/bc516598-1c43-48ca-976f-5b13da9445e7" />

### Installation

Add this repository as a plugin source in Noctalia:

```bash
noctalia msg plugins source add syncro-plugins git <https://github.com/awsumatt/syncro-noctalia-plugins.git>
```
**OR**

<img width="853" height="338" alt="image" src="https://github.com/user-attachments/assets/ec956469-550c-42f9-9fbe-0c141dd14952" />


Then enable the desired plugins from the Noctalia plugin manager/settings.
